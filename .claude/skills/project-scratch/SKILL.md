When the user wants to share a screenshot with the AI agent, he will invoke this skill. Look at a folder in the project
named "scratch", probably in the root folder. The folder may contain multiple files. Look for the newest file(s). It will
contain screenshots or other artifacts that the user wants to bring to the notice of or use by the AI agent.

If not found, look in the "scratch" folder in the frontend or backend folder.
