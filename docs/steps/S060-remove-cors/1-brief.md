# S060 — Remove flask-cors

KLA, 26-10-2026: "why does access control allow origin on vel-yantra.mspv.app list localhost?",
then "step fix remove flask-cors".

## The bug

Production's responses carry `Access-Control-Allow-Origin: http://localhost:5176`, the Vite dev
server's address.

**To see it:** request any page or `/api/health` on production with no `Origin` header (a
same-origin load) and read the response headers.

**Cause (checked):**
- `backend/app.py:45`: `CORS(app, origins=os.environ.get("CORS_ORIGINS", "http://localhost:5176").split(","))`.
  Nothing sets `CORS_ORIGINS` in production (no hit in `smtw_erp_devops/erp_server/yantra`), so
  the dev default applies.
- Flask-CORS's `always_send` branch (`flask_cors/core.py:255-270`, version 6.0.5) sends every
  literal origin when the request has no `Origin` header.

**Why CORS is not needed at all:** production serves the frontend and `/api` from one origin
(Nginx); in dev Vite proxies `/api` (`frontend/vite.config.js:39-45`). No cross-origin caller
exists. Harm today is low (bearer tokens, no credentials allowed), but it is a dev value in
production and a security-scan finding.

## The fix

Remove Flask-CORS: no cross-origin access, no `Access-Control-*` headers.
- `backend/app.py`: drop the import and the `CORS(...)` line; reword the comment at `:41-43`
  (the access-log hook stays the first `after_request` hook registered, for any later one).
- `backend/access_control.py:244-247`: the docstring drops "(CORS's included)".
- `backend/pyproject.toml` and `backend/uv.lock`: remove `flask-cors` (`uv remove flask-cors` in
  `backend/`, the repo's own lockfile).
- `sbom/backend.cdx.json`: regenerated by `tooling/run-deps-audit.bat` (CLAUDE-COMMON § Software
  inventory: never by hand).
- The test that fails on the bug: `backend/tests/test_health.py` gains a test that `/api/health`,
  with no `Origin` header and with `Origin: http://localhost:5176`, carries no
  `Access-Control-Allow-Origin` header. Red on the current code, green after.

**Docs:** `.claude/CLAUDE.md`: none due. `.claude/SMTW-WebApp-Base.md:1431` (synced) names
`flask-cors` in the new-project setup line: a text for smtw-common in the impl report (drop it;
the app is same-origin behind Nginx and Vite's proxy).
